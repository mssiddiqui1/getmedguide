Introduction to COC

What the Certified Outpatient Coder credential covers, and how facility outpatient coding differs from physician coding.

What COC is

The Certified Outpatient Coder (COC) credential, from AAPC, focuses specifically on facility-side outpatient coding — hospital outpatient departments and ambulatory surgery centers (ASCs). This is a different claim and a different rule set than the physician's own professional coding for the same visit.

The outpatient facility coding flow

COC covers facility-side outpatient coding — the hospital or ASC's claim, not the physician's separate professional claim.

Key concepts unique to outpatient facility coding

ConceptWhat it means
APCsAmbulatory Payment Classifications — the payment grouping system Medicare uses for hospital outpatient services, similar in spirit to inpatient DRGs
OCE editsOutpatient Code Editor — automated checks that flag code combinations that can't be billed together
UB-04The standard facility claim form (institutional claim)
Modifier -25 / -59Facility-side modifiers with their own specific rules, distinct from how they're used on a physician claim

Who should pursue COC

Coders aiming for a job specifically in a hospital outpatient department, ASC, or facility billing office — as opposed to a physician practice (CPC) or inpatient hospital coding (CIC).
