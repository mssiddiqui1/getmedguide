CPC Cheat Sheet

A one-glance reference for the code ranges, modifiers, and rules most likely to trip you up on exam day.

Exam at a glance

  • 100 multiple-choice questions (including ~10 case studies)
  • 4 hours, one session → roughly 2 min 24 sec per question
  • Open book — your printed CPT, ICD-10-CM & HCPCS manuals
  • Pass mark: 70% · open book ≠ easy — speed of lookup is the real skill

ICD-10-CM guideline reminders

  • Always start in the Alphabetic Index, then verify the full code in the Tabular List — never code from the Index alone.
  • 7th character: A = initial encounter · D = subsequent encounter · S = sequela.
  • "Code first" means sequencing the underlying/etiology code before this one.
  • Combination codes capture two conditions in a single code (for example, diabetes with a manifestation).
  • Use laterality (right/left) and the most specific code the documentation supports.
  • Use "unspecified" only when the documentation genuinely won't support more detail.

E/M quick guide (2021+ rules)

  • Office visits are leveled by Medical Decision-Making (MDM) or total time — whichever is higher.
  • MDM = problems addressed + data reviewed + risk.
  • New patient: 99202–99205 · Established patient: 99211–99215.
  • History and exam no longer drive the level — they just need to be medically appropriate.

Open-book & exam-day strategy

  • Tab your manuals by section — highlighting is fine, long handwritten notes are not.
  • Use a 3-pass method: easy questions first, flagged lookups next, case studies last.
  • Never spend more than about 4 minutes on one question — flag it and move on.
  • Eliminate two wrong answers, then verify the remaining code in the book.
  • Read E/M and operative-note case studies twice — the detail usually decides the code.
  • Leave no blanks — there's no penalty for guessing.

Note: this is a study aid, not a substitute for the official AAPC materials or your current-year code manuals. Code sets, ranges, and exam rules update annually — always confirm against your current CPT, ICD-10-CM, and HCPCS books and aapc.com.
